# Vercel Deployment — Nexus Global Safety 360

## Build settings

- Framework: Next.js
- Build command: `npm run build`
- Install command: `npm ci`
- Output: static export generated by Next.js
- Environment variables: none required

## Deployment

Connect the GitHub repository to Vercel and deploy from the `main` branch. Vercel will install dependencies and run the production build automatically.

## Application access

- Employee ID: `NGL-001`
- Administrator ID: `NGL-ADMIN`

Application state is stored in the browser, so each browser maintains its own training and administration state.
