# Nexus Global Safety 360 — Frontend Foundation

This project is the frontend-only deployment edition of Nexus Global Safety 360.

## Architecture

- Next.js 16
- React 19
- Static export
- Browser-based authentication state
- Browser-local application persistence
- Employee portal
- Administration portal
- Six safety training modules
- Progress, scoring, achievements and certificates
- User, department, module and assignment administration

The application has no runtime dependency on NestJS, Prisma or PostgreSQL.
